We made use of constrasting primary colours and grascale secondary colours to hightlight the important information so the user can immediately locate it. For example, important buttons such as logout and create listing button use a contrasting blue. The delete listing button also uses a contrasting red for user to immediately see and correspond this button as a delete button.

Trying to delete a listing also triggers a popup to confirm if the user is trying to delete this listing. This is to ensure the user does not accidentally delete the listing.

Some sections are enclosed in a slightly darker box from the background or have a border to distinguish specific sections from one another, such as the filter and booking request section.

The navigation bar is fixed to the top of the page to improve ease of navigation.

Upon load, the edit listing form sets the current values of into their respective input field so user can see and edit the correct value.

Any elements that can be interacted with, such as the buttons, inputs and listings, have hover animation to provide visual feedback to show the users the element can be interacted with.

We used grids structure for listing to display more listings in less space to reduce the amount of scrolling for users.

We have broken up the listing form and filter form into sections with headings for users to easily navigate the form.
